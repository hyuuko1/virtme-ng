# Triage Labels

工程技能基于 5 个标准分流（Triage）角色进行工作。本文档将这些角色映射至本仓库 Issue 跟踪系统所使用的实际标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此问题                     |
| `needs-info`               | `needs-info`         | 等待提交者提供更多信息                   |
| `ready-for-agent`          | `ready-for-agent`    | 规范完备，可交由离线 Agent 执行          |
| `ready-for-human`          | `ready-for-human`    | 需要人工介入实现                         |
| `wontfix`                  | `wontfix`            | 不予处理                                 |

当技能提及某一角色时（例如“应用可交由 Agent 处理的分流标签”），请使用本表中对应的标签字符串。

若后续调整分流词汇，请直接编辑右侧列以匹配实际使用的标签。
